Diabetic Retinopathy Screening

It refuses to guess.

NetraTrust grades diabetic retinopathy on the device that took the photograph. When the image is unreadable, or the model is not sure enough, it says so — instead of inventing a number.

Open the screening app How it works

Offline-first · Images never leave the device

01 · Image quality gate

A bad photograph is not a diagnosis.

Every fundus image is scored before anything is graded: usable, borderline or reject, each with a reason code. A failed gate returns no result — never a negative one.

Clear image 997/1000 usable · Blurred 21/1000 → reject (focus)

Capture an image

02 · Conformal abstention

Uncertainty, measured not assumed.

Split-conformal prediction returns every grade still plausible at 90% confidence. When that set spans more than one clinical action, the case goes to a clinician rather than to a label.

QWK 0.886 · Coverage 0.939 · Abstains on 6.1% · Mean set 1.18

See a graded case

03 · Per-site reliability

Every camp reports its own truth.

Accuracy is a distribution across sites, not a headline number. Each screening site carries its own Wilson interval, and no rate is shown as a bare percentage below thirty cases.

Wilson 95% intervals · under n=30 it shows counts, not percentages

Open site monitor

04 · Tamper-evident ledger

Every decision leaves a trace.

Each clinical decision is appended to a SHA-256 hash chain, signed with Ed25519 over canonical JSON, before any result is returned. Alter one entry and verification fails at its exact index.

SHA-256 chain · Ed25519 · RFC-8785 · Append-only

Built for the field

No signal, no problem.

Screen all morning with no network. Each encounter is queued on the device under its own idempotency key and replayed in order when signal returns, so a retry can never double-count a patient.
